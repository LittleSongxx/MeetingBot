# cross30 体检结论（2026-10-27，P0）

> 数据：M1b packet 的 cross30 30 题 × 3 次 r1 判定；逐题明细 `cross30_diagnosis.csv`。

## 结论

1. **cross30 的 CP 低主要是仪器效应，不是检索坏了**：30 题里大量 `CP=0` 但 `CR=1`、答案与 reference 字符重叠 0.65–0.97（m001–m006 等）。RAGAS CP 要求"单个 context 支持完整 reference"，多事实答案的事实分散在多个切片时结构性地判 0。m001 实测：单事实 reference CP 0.25–0.37、合并 reference 0.33（重跑还能出 0.0），judge 不稳定。
2. **7/30 题答案含"资料不足/未确认/草稿"等否定式表述**；其中 m016/m018 语义正确但 AR=0（RAGAS AR 用"反推问题 embedding"，否定式回答与原始问句相似度低），faith 0.12/0.20（contexts 未覆盖其断言）。这属于**答案风格 + 上下文/参考不齐**的混合问题。
3. **少数题是数据/参考不匹配**：m007（CP 0、CR 0、答案重叠 0.79）等；需要 gold/reference 复核，不能靠调系统修。
4. 真实可优化空间：faith/AR 的尾部 case（否定式、直接回应、无关背景）、CR 的 cross30 覆盖；**官方 CP 整体 ≥90 不可达**，除非改评测单位/参考（自定义仪器）或改数据。

## 对 P1/P2 的含义

- P1（答案风格）目标：faith/AR 向 90 靠拢；规则：第一句直接回答；否定式先回应问题对象；不写"如需进一步检索"等套话；数字/日期/人名与引用一致；只写有 [n] 支持的内容；单事实题不展开背景。
- P2（覆盖）目标：CR 向 90；cross30 结构化覆盖（先列相关会议/系列→逐项检索→覆盖回执），不是加长 prompt。
- CP：走路线 A（官方口径下现实目标 75–80，分层报告）或路线 B（自定义 fact-aligned CP，标 r1-fact，不冒充官方）；不通过调检索硬刷官方 CP。

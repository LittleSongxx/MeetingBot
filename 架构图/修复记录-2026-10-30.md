## 二、安全与权限（P1）

| 问题 | 修复 |
|---|---|
| **存储型 XSS**：`Meeting.vue` 删除确认框用 `dangerouslyUseHTMLString` 拼接用户可控会议标题，配合 localStorage token 可窃取管理员会话 | 改为 `h()` VNode 结构化渲染（标题纯文本 + 数据列表），移除 `dangerouslyUseHTMLString`；全仓无 `v-html/innerHTML` |
| **任意会议可见者可覆盖已确认纪要**（`generate` 只校验会议可见、清空 CONFIRMED 内容并改 `created_by`） | 重新生成要求管理员或纪要创建人；CONFIRMED 必须先取消确认；有 RUNNING/WAITING_CONFIRMATION 自检时禁止重生成；重生成时同步清理旧自检运行（调用日志保留审计） |
| **写/删权限口径不一致**：参会人可删他人资料、替他人重试转写、编辑/确认他人纪要、反复发起付费自检 | 统一为：读=会议可见；写/删=管理员或对应对象创建人（资料上传人/转写发起人/纪要创建人/自检发起人）；昂贵操作加 3~5 秒连点冷却 |
| **登录无限试密码** | 同账号+来源连续 5 次失败锁定 5 分钟（单进程内存实现）；登录接口补 `Request` 取来源 IP |
| **API 文档无鉴权暴露** | `/docs`、`/redoc`、`/openapi.json` 默认关闭；本机调试需 `DOCS_ENABLED=1` |
| **CORS 缺省放行 + 异常处理器硬编码 `ACAO:*`** | 默认同源（空列表）；删除异常处理器里手写的 `ACAO:*`，跨域统一交给中间件 |
| **注册开关默认开、密码无最低长度** | `REGISTER_ENABLED` 代码默认改为 `False`（与 `.env.example` 一致）；注册/改密/新增用户统一最低 6 位校验 |
| **头像/资料下载响应无安全头** | `FileResponse` 补 `X-Content-Type-Options: nosniff`；nginx 侧补 CSP/X-Frame-Options/nosniff/Referrer-Policy/Permissions-Policy |

## 三、Agent 与任务可靠性（P1）

| 问题 | 修复 |
|---|---|
| **最后一轮重写被中断后恢复直接 finalize**：结论称已重写，实际修订稿是上一轮的 | `execute_agent_run` 先判断「中断未完成的重写」，再判断轮数上限；有未完成重写时不提前收尾 |
| **resume 无 CAS、旧协程未退出时可能卡 RUNNING** | `resume` 改为带 `status=INTERRUPTED` 的条件更新；`schedule_agent_run` 在旧任务未结束时注册回调，退出后按状态补调度 |
| **apply 无版本绑定**：等待确认期间纪要可被编辑/重生成，旧修订稿会覆盖新内容 | 只允许 DRAFT 应用（CONFIRMED/GENERATING/FAILED 均拒绝）；`minutes.update_time > run.finished_at` 时提示「纪要已被修改，请重新发起自检」 |
| **失败的 Agent 运行无重试入口** | 新增 `PUT /agent/retry/{run_id}`：FAILED 且纪要可用时从已完成轮次续跑（不新建运行重复计费） |
| **删除会议/纪要时后台任务仍在跑**：产生孤儿行并继续消耗模型费用 | 删除会议前检查三类运行中任务并拒绝；删除纪要前检查自检 RUNNING 并拒绝 |
| **自检详情可顺着会议可见看到同事运行** | `selectByMinutes` 按「管理员/运行发起人/纪要创建人」过滤，否则返回 `None` |
| **SSE 每秒查库、被删运行流内 500、无心跳** | 改为 `get_or_none`（被删时推 terminated 事件并结束）、每 15 秒心跳、终态主动关闭 |
| **`except Exception` 把 INTERRUPTED 覆盖成 FAILED** | 兜底改为带 `status=RUNNING` 条件更新 |
| **ai_call_log 无限增长** | 新增 `AI_CALL_LOG_RETENTION_DAYS`（默认 365），启动时清理过期日志；schema 增加 `idx_ai_call_create_time` 索引（已对本地库执行 ALTER） |

## 四、API 边界与工程化（P1/P2）

| 问题 | 修复 |

## 七、本轮未处理（架构级已知限制，非本次「bug 修复」范围）

1. **单进程任务编排**：无消息队列/独立 worker；崩溃恢复会从头重跑（可能与重复计费），多副本仍禁止（README/DEPLOYMENT 已写明）。

3. **观测页 Python 内存聚合**：已加范围上限与索引，但未改成 SQL GROUP BY 聚合。
4. **AI Agent 能力缺口**（无工具调用/检索/对话/记忆/评测）：属于产品演进方向，见分析报告第 5 节与 `agent-gaps.md`，不在本轮 bug 修复内。

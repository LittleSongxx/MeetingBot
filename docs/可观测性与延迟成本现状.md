# Agent 延迟 / 成本 / 可观测性现状（2026-10-23）

> 结论先说：**测了"模型调用级 + 任务级"，没有完整测"Chat 图节点级 / 工具级 / 单轮端到端"**；
> 成本**没有真实数值**（所有模型单价为 0，25,036 次调用全部 unpriced）；
> 可观测性有账本、概览页、Prometheus `/metrics`，但 **OTLP 导出默认关闭、无 trace 后端**。
> 本报告只做现状盘点与下一步计划，不宣称生产级可观测性。

## 4. 可观测性现有能力

- **账本**：`ai_call_log`（call_type / biz_id / model / elapsed_ms / tokens / cost_micro /
  status / error / trace_id / span_id），25k 条；可按 trace_id 回放一次问答的全部模型调用。
- **概览页**：`/observability/overview`（八卡片、四图、模型排行、最近失败、Agent 步骤统计）。
- **Prometheus**：`/metrics` 暴露
  `gen_ai_client_token_usage_total`、`gen_ai_client_operation_duration_seconds`（直方图）、
  `meetingbot_ai_call_cost_micro_total`、`meetingbot_ai_call_unpriced_total`。
- **Agent 步骤**：`agent_step.elapsed_ms` 记录 REVIEW/REFINE/FINAL（纪要自检环），
  `/observability/overview` 有按步骤类型均值。
- **Trace**：`trace_id` 贯穿请求、`chat_message.trace_id`、`ai_call_log.trace_id/span_id`；
  代码里有 `gen_ai.*` 模型 span、`chat.tool` 工具 span、Temporal activity span，
  但 **`OTEL_EXPORTER_OTLP_ENDPOINT` 未配置 → span 只生成不导出**，没有 Jaeger/Tempo/APM 可查。
- **没有**：Grafana/告警规则、Chat 图节点耗时、工具执行耗时落库、单轮端到端耗时字段、
  成本告警（unpriced 比例/预算）。

## 5. 关键缺口（按影响排序）

1. **成本不可信**：全部 unpriced；无法回答"一次问答/一分钟音频多少钱"。
2. **Chat 阶段级延迟缺失**：agent / tools / coverage / nudge / finalize 的节点耗时没有落库；
   工具耗时只在 OTel span 里（且不导出），`tools_json` 不含 duration。
3. **端到端单轮延迟缺失**：`ChatMessage` 只有 token_count/stop_reason/trace_id，没有 elapsed_ms；
   只能从 ai_call_log 派生"模型+检索"时间。
4. **长延迟项缺治理**：CHAT_SUMMARY p50 16s/p95 52s、CHAT max 122s、MINUTES 296s，
   没有预算/告警/超时策略的分层指标。
5. **trace 无后端**：排障只能 SQL 按 trace_id 聚合，不能看瀑布图。
6. **基线过期**：2026-10-20 的延迟/成本报告早于 MOSS、引用绑定、工具契约扩展；
   MOSS 基板没有 e2e 延迟/成本重测。

## 8. P0 已落地（2026-10-23 晚）

1. **单轮阶段耗时已落库**：`chat_message.moderation_json.timing` =
   `{total_ms, nodes:{agent,tools,coverage,nudge,finalize}, tools:[{name,call_id,elapsed_ms}]}`。
   实测一轮：total **8571ms**，agent **7670ms**、tools **854ms**、search_knowledge **837ms**
   —— Chat 的延迟主要在图内 agent（模型轮次），不在检索。**没有新增表/列**，避免迁移链风险。
2. **观测页 p50/p95**：`/observability/overview` 的 `summary`、`call_types`、`step_ranking`
   现在返回 `p50_elapsed_ms/p95_elapsed_ms`（最近秩，口径与报告一致）；`summary` 增加
   `unpriced_ratio`。`percentile` 有单测。
3. **成本单价已配置（估算值，非账单）**：`db/03-model-prices.sql` 写入
   qwen3.8-max-0902 = 11715/35152 微元每 1k input/output（官方 USD 价 × 7.1 汇率估算）、
   embedding = 500 微元每 1k。**新调用已能算出 cost_micro**：实测一轮 4 次 CHAT
   合计约 **¥0.23**（单次 4k–6k token 约 ¥0.05–0.07），检索嵌入/重排约 ¥0.002。
   **历史调用仍是 unpriced，不会按新价重估**；ASR（GPU/时长计费）与 deepseek 裁判仍不在此表。

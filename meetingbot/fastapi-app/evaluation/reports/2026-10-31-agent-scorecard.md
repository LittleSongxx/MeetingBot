# Agent 产品指标 Scorecard（2026-10-31）

> 这份报告不看 ROUGE 论文分数，只看 **Agent 产品行为**：任务完成、人工接管、调用可靠性、证据接地、行动项可用性、延迟/成本。
> 数据来自评测栈 `meetingbot-aim-eval` 的演示会议（1 场）+ 2 次自检运行，样本很小，不能作为统计结论。
> 默认排除 `request_id` 以 `AICDEMO` 开头的演示种子日志和 `AGR-DEMO` 自检运行，避免把 demo 假失败当成真实可靠性；可用 `--include-demo` 复现旧口径。

### 2.6 QA 测试集（20 题，含 4 道不可回答、8 道多证据）

为补上 QA 只有调用日志的缺口，新增 [`../golden/qa_demo.json`](../golden/qa_demo.json) 和 `evaluation/qa_eval.py`。QA 集从 14 题扩到 **20 题**（16 可回答 + 4 不可回答，8 道多证据），做了 3 次真实运行以观察方差：

| 指标 | 当前 | 目标 |
|---|---|---|
| 20 题平均 found 率 | **95.83%**（3 次：100/93.75/93.75） | ≥90% |
| 不可回答题拒答准确率 | **100%（2/2）** | ≥90% |
| 20 题平均引用 precision | **83.38%**（3 次：82.61/85.71/81.82） | ≥90% |
| 20 题平均引用 recall | **79.71%**（3 次：82.61/78.26/78.26） | ≥80% |
| 20 题平均引用 F1 | **0.8148** | - |
| 20 题平均答案相似度 | **0.5050** | 参考，不作硬门槛 |

校准动作：拒答保护只检查**第一句**——如果开头是“未找到/没有提及”才改判拒答；正文后文的“材料未提及……”只是补充说明，不再误杀。连续 3 次 20 题运行后，**拒答率稳定 100%**，found 率回到 93.75~100%，引用 precision/recall 为 81.82~85.71% / 78.26~82.61%。false negative 减少，但 precision/recall 仍未稳定达到 90%/80% 目标。**单次高指标不可信。**

发现并修复了一个评测脚本问题：QA 接口同一用户有 3 秒冷却，脚本首版连续调用被服务端拒绝，被误记为“未找到依据”；现在评测脚本会按 3.2s 间隔调用。这个细节说明**评测工具本身也要按真实 API 约束设计**。

## 3. 结论

**Agent 已经具备产品形态的行为指标**：

- 自检反思环能正常终止（fresh run 1 轮、3 步、72s，无失控循环）；
- 人工确认节点存在，且决策延迟可观测；
- 行动项确认/负责人/截止/重复率有数据可查；
- 调用可靠性、延迟、Token 已有统一日志。

**当前主要差距：**

1. **真实调用可靠性 100%（110/110）**，但样本仍小；之前统计到的 1 次失败来自 `demo_seed` 假日志，已通过 `demo_excluded` 排除，说明 scorecard 自身也有“演示数据污染”风险；
2. **证据覆盖率 95%**，只差 1 条，但样本只有 1 场；需真实会议量验证；
3. **QA 引用 precision 83.38%、recall 79.71%**（20 题 ×3 次）；拒答率稳定 100%，found 率 95.83%，但 precision/recall 仍未达到 90%/80%，多证据题仍有漏引/误引；
4. **人工修改率 0%**，没有真实编辑行为，不能说明“终稿质量”；
5. **样本仍只有 1 场会议、2 个自检运行**；QA 已扩到 10 题，但行动项/人工编辑仍缺少真实业务数据。

## 4. 建议的 Agent 验收线

| 维度 | 指标 | 目标 |
|---|---|---|
| 任务 | Agent 终态完成率 | ≥95% |
| 任务 | 步骤成功率 | ≥99% |
| 可靠性 | 模型调用成功率 | ≥99% |
| 可靠性 | 运行 P95 耗时 | 依会议长度设定，建议 < 5min |
| 接地 | 条目证据覆盖率 | ≥95% → 100% |
| 接地 | 引用合法率 | ≥99% |
| 接地 | 无依据声明率 | <5% |
| 行动项 | content F1（内部集） | ≥0.75 |
| 行动项 | owner / due 覆盖 | ≥80% / ≥70% |
| 行动项 | 近似重复率 | <5% |
| QA | 引用 precision / recall | ≥0.9 / ≥0.8 |
| QA | 不可回答题拒答率 | ≥90% |
| 人工 | 确认决策延迟 | 持续观测，不强行最小化（人工确认是设计） |

> 这些是产品验收建议，不是论文指标；需要在内部 golden set（10~20 场真实会议）上重新测。

## 3. 结论

**Agent 已经具备产品形态的行为指标**：

- 自检反思环能正常终止（fresh run 1 轮、3 步、72s，无失控循环）；
- 人工确认节点存在，且决策延迟可观测；
- 行动项确认/负责人/截止/重复率有数据可查；
- 调用可靠性、延迟、Token 已有统一日志。

**当前主要差距：**

1. **调用可靠性 92.86% 低于 99%**，有一次 MINUTES_CHUNK 空响应；需要判断是偶发还是模型/prompt 问题；
2. **证据覆盖率 95%**，只差 1 条，但样本只有 1 场；需真实会议量验证；
3. **QA 只有调用层指标**，引用正确率、拒答准确率没有持久化/样本评测；
4. **人工修改率 0%**，没有真实编辑行为，不能说明“终稿质量”；
5. **样本只有 1 场会议、2 个自检运行**，人工确认/接受率不能当产品结论（本次两个 run 都主动 reject）。

## 4. 建议的 Agent 验收线

| 维度 | 指标 | 目标 |
|---|---|---|
| 任务 | Agent 终态完成率 | ≥95% |
| 任务 | 步骤成功率 | ≥99% |
| 可靠性 | 模型调用成功率 | ≥99% |
| 可靠性 | 运行 P95 耗时 | 依会议长度设定，建议 < 5min |
| 接地 | 条目证据覆盖率 | ≥95% → 100% |
| 接地 | 引用合法率 | ≥99% |
| 接地 | 无依据声明率 | <5% |
| 行动项 | content F1（内部集） | ≥0.75 |
| 行动项 | owner / due 覆盖 | ≥80% / ≥70% |
| 行动项 | 近似重复率 | <5% |
| QA | 引用 precision / recall | ≥0.9 / ≥0.8 |
| QA | 不可回答题拒答率 | ≥90% |
| 人工 | 确认决策延迟 | 持续观测，不强行最小化（人工确认是设计） |

> 这些是产品验收建议，不是论文指标；需要在内部 golden set（10~20 场真实会议）上重新测。

## 5. 复现
